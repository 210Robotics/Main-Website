40 /** Motor movement functions **/
41 /** **/
42 /** These functions allow programmers to make motors move **/
43 /******************************************************************************/

45 /**
46 * Sets the target absolute position for the motor to move to.
47 *
48 * This movement is relative to the position of the motor when initialized or
49 * the position when it was most recently reset with setZeroPosition().
50 *
51 * @note This function simply sets the target for the motor, it does not block program execution
52 * until the movement finishes.
53 *
54 * @param iposition The absolute position to move to in the motor's encoder units
55 * @param ivelocity The maximum allowable velocity for the movement in RPM
56 * @return 1 if the operation was successful or `PROS_ERR` if the operation failed, setting errno.
57 */
58 std::int32_t moveAbsolute(double iposition, std::int32_t ivelocity) override;
59
60 /**
61 * Sets the relative target position for the motor to move to.
62 *
63 * This movement is relative to the current position of the motor. Providing 10.0 as the position
64 * parameter would result in the motor moving clockwise 10 units, no matter what the current
65 * position is.
66 *
67 * @note This function simply sets the target for the motor, it does not block program execution
68 * until the movement finishes.
69 *
70 * @param iposition The relative position to move to in the motor's encoder units
71 * @param ivelocity The maximum allowable velocity for the movement in RPM
72 * @return 1 if the operation was successful or `PROS_ERR` if the operation failed, setting errno.
73 */
74 std::int32_t moveRelative(double iposition, std::int32_t ivelocity) override;
75
76 /**
77 * Sets the velocity for the motor.
78 *
79 * This velocity corresponds to different actual speeds depending on the gearset
80 * used for the motor. This results in a range of +-100 for pros::c::red,
81 * +-200 for green, and +-600 for blue. The velocity
82 * is held with PID to ensure consistent speed, as opposed to setting the motor's
83 * voltage.
84 *
85 * @param ivelocity The new motor velocity from -+-100, +-200, or +-600 depending on the motor's
86 * gearset
87 * @return 1 if the operation was successful or `PROS_ERR` if the operation failed, setting errno.
88 */
89 std::int32_t moveVelocity(std::int16_t ivelocity) override;
90
91 /**
92 * Sets the voltage for the motor from `-12000` to `12000`.
93 *
94 * @param ivoltage The new voltage value from `-12000` to `12000`.
95 * @return 1 if the operation was successful or `PROS_ERR` if the operation failed, setting errno.
96 */
97 std::int32_t moveVoltage(std::int16_t ivoltage) override;
98
99 /**
100 * Changes the output velocity for a profiled movement (moveAbsolute or moveRelative). This will
101 * have no effect if the motor is not following a profiled movement.
102 *
103 * @param ivelocity The new motor velocity from `+-100`, `+-200`, or `+-600` depending on the
104 * motor's gearset.
105 * @return 1 if the operation was successful or `PROS_ERR` if the operation failed, setting errno.
106 */
107 std::int32_t modifyProfiledVelocity(std::int32_t ivelocity) override;
