27 * \image html llemu/llemu-3.8.png

29 * LLEMU provides a virtual 40x8 LCD screen with 3 buttons. The user can set the

329/**
330 * Gets the button status from the emulated three-button LCD.
331 *
332 * The value returned is a 3-bit integer where 1 0 0 indicates the left button
333 * is pressed, 0 1 0 indicates the center button is pressed, and 0 0 1
334 * indicates the right button is pressed. 0 is returned if no buttons are
335 * currently being pressed.
336 *
337 * Note that this function is provided for legacy API compatibility purposes,
338 * with the caveat that the V5 touch screen does not actually support pressing
339 * multiple points on the screen at the same time.
340 *
341 * \return The buttons pressed as a bit mask
342 *
343 * \b Example
344 * \code
345 * #include "pros/llemu.hpp"
346 *
347 * void initialize() {
348 * pros::lcd::initialize();
349 * }
350 *
351 * void opcontrol() {
352 * while(true) {
353 * std::uint8_t state = pros::lcd::read_buttons();
354 * pros::lcd::print(0, "%d %d %d",
355 * (state & LCD_BTN_LEFT) >> 2
356 * (state & LCD_BTN_CENTER) >> 1,
357 * (state & LCD_BTN_RIGHT) >> 0
358 * );
359 *
360 * pros::delay(10);
361 * }
362 * }
363 * \endcode
364 */
365std::uint8_t read_buttons(void);
