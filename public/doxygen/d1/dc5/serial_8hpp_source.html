104 /**
105 * Clears the internal input and output FIFO buffers.
106 *
107 * This can be useful to reset state and remove old, potentially unneeded data
108 * from the input FIFO buffer or to cancel sending any data in the output FIFO
109 * buffer.
110 *
111 * \note This function does not cause the data in the output buffer to be
112 * written, it simply clears the internal buffers. Unlike stdout, generic
113 * serial does not use buffered IO (the FIFO buffers are written as soon
114 * as possible).
115 *
116 * This function uses the following values of errno when an error state is
117 * reached:
118 * EINVAL - The given value is not within the range of V5 ports (1-21).
119 * EACCES - Another resource is currently trying to access the port.
120 *
121 * \return 1 if the operation was successful or PROS_ERR if the operation
122 * failed, setting errno.
123 *
124 * \b Example:

126 * pros::Serial serial(1);

128 * \endcode
