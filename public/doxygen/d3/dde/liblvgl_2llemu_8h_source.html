2 * \file liblvgl/llemu.h
3 * \ingroup c-llemu
4 *
5 * Legacy LCD Emulator
6 *
7 * \details This file defines a high-level API for emulating the three-button, UART-based
8 * VEX LCD, containing a set of functions that facilitate the use of a software-
9 * emulated version of the classic VEX LCD module.
10 *
11 * Visit https://pros.cs.purdue.edu/v5/tutorials/topical/adi.html to learn more.
12 *
13 * This file should not be modified by users, since it gets replaced whenever
14 * a kernel upgrade occurs.
15 *
16 * \copyright (c) 2017-2023, Purdue University ACM SIGBots.
17 *
18 * This Source Code Form is subject to the terms of the Mozilla Public
19 * License, v. 2.0. If a copy of the MPL was not distributed with this
20 * file, You can obtain one at http://mozilla.org/MPL/2.0/.
21 *
22 * \defgroup c-llemu LLEMU C API
23 * @{
24 * LLEMU - <B>L</B>egacy <B>L</B>cd <B>EMU</B>lator
25 *
26 * \image html llemu/llemu-3.8.png
27 *
28 * LLEMU provides a virtual 40x8 LCD screen with 3 buttons. The user can set the
29 * text of the screen and set create functions that are run when the buttons are
30 * pressed.
31 *
32 * LLEMU is a emulation of the UART-based LCD screens that were available with
33 * VEX's cortex product line.
34 * @}
35 */

388/**
389 * Gets the button status from the emulated three-button LCD.
390 *
391 * The value returned is a 3-bit integer where 1 0 0 indicates the left button
392 * is pressed, 0 1 0 indicates the center button is pressed, and 0 0 1
393 * indicates the right button is pressed. 0 is returned if no buttons are
394 * currently being pressed.
395 *
396 * Note that this function is provided for legacy API compatibility purposes,
397 * with the caveat that the V5 touch screen does not actually support pressing
398 * multiple points on the screen at the same time.
399 *
400 * \return The buttons pressed as a bit mask
401 */
402uint8_t lcd_read_buttons(void);
