29 /**
30 * A gyroscope on the given ADI port. If the port has not previously been configured as a gyro,
31 * then the constructor will block for 1 second for calibration. The gyro measures in tenths of a
32 * degree, so there are 3600 measurement points per revolution.
33 *
34 * ```cpp
35 * auto gyro = ADIGyro({1, 'A'}, 1);
36 * ```
37 *
38 * Note to developers: Keep the default value on imultiplier so that users get an error if they do

40 *
41 * @param iports The ports the gyro is plugged in to in the order ``{smart port, gyro port}``. The
42 * smart port is the smart port number (``[1, 21]``). The gyro port is the ADI port number (``[1,
43 * 8]``, ``[a, h]``, ``[A, H]``).
44 * @param imultiplier A value multiplied by the gyro heading value.
45 */
46 ADIGyro(std::pair<std::uint8_t, std::uint8_t> iports, double imultiplier = 1);
