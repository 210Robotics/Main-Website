76 /**
77 * Sets the target absolute position for the motor to move to.
78 *
79 * This movement is relative to the position of the motor when initialized or
80 * the position when it was most recently reset with setZeroPosition().
81 *
82 * @note This function simply sets the target for the motor, it does not block program execution
83 * until the movement finishes.
84 *
85 * This function uses the following values of errno when an error state is reached:
86 * EACCES - Another resource is currently trying to access the port.
87 *
88 * @param iposition The absolute position to move to in the motor's encoder units
89 * @param ivelocity The maximum allowable velocity for the movement in RPM
90 * @return 1 if the operation was successful or PROS_ERR if the operation failed, setting errno.
91 */
92 virtual std::int32_t moveAbsolute(double iposition, std::int32_t ivelocity) = 0;
93
94 /**
95 * Sets the relative target position for the motor to move to.
96 *
97 * This movement is relative to the current position of the motor. Providing 10.0 as the position
98 * parameter would result in the motor moving clockwise 10 units, no matter what the current
99 * position is.
100 *
101 * @note This function simply sets the target for the motor, it does not block program execution
102 * until the movement finishes.
103 *
104 * This function uses the following values of errno when an error state is reached:
105 * EACCES - Another resource is currently trying to access the port.
106 *
107 * @param iposition The relative position to move to in the motor's encoder units
108 * @param ivelocity The maximum allowable velocity for the movement in RPM
109 * @return 1 if the operation was successful or PROS_ERR if the operation failed, setting errno.
110 */
111 virtual std::int32_t moveRelative(double iposition, std::int32_t ivelocity) = 0;
112
113 /**
114 * Sets the velocity for the motor.
115 *
116 * This velocity corresponds to different actual speeds depending on the gearset
117 * used for the motor. This results in a range of +-100 for pros::c::red,
118 * +-200 for green, and +-600 for blue. The velocity
119 * is held with PID to ensure consistent speed, as opposed to setting the motor's
120 * voltage.
121 *
122 * This function uses the following values of errno when an error state is reached:
123 * EACCES - Another resource is currently trying to access the port.
124 *
125 * @param ivelocity The new motor velocity from -+-100, +-200, or +-600 depending on the motor's
126 * gearset
127 * @return 1 if the operation was successful or PROS_ERR if the operation failed, setting errno.
128 */
129 virtual std::int32_t moveVelocity(std::int16_t ivelocity) = 0;
130
131 /**
132 * Sets the voltage for the motor from -12000 to 12000.
133 *
134 * This function uses the following values of errno when an error state is reached:
135 * EACCES - Another resource is currently trying to access the port.
136 *
137 * @param ivoltage The new voltage value from -12000 to 12000
138 * @return 1 if the operation was successful or PROS_ERR if the operation failed, setting errno.
