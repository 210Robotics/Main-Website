49 /**
50 * Generates a path which intersects the given waypoints and saves it internally with a key of
51 * pathId. Call `executePath()` with the same pathId to run it.
52 *
53 * If the waypoints form a path which is impossible to achieve, an instance of
54 * `std::runtime_error` is thrown (and an error is logged) which describes the waypoints. If there
55 * are no waypoints, no path is generated.
56 *
57 * @param iwaypoints The waypoints to hit on the path.
58 * @param ipathId A unique identifier to save the path with.
59 */

62 /**
63 * Generates a path which intersects the given waypoints and saves it internally with a key of
64 * pathId. Call `executePath()` with the same pathId to run it.
65 *
66 * If the waypoints form a path which is impossible to achieve, an instance of
67 * `std::runtime_error` is thrown (and an error is logged) which describes the waypoints. If there
68 * are no waypoints, no path is generated.
69 *
70 * NOTE: The waypoints are expected to be in the
71 * okapi::State::FRAME_TRANSFORMATION format where +x is forward, +y is right,
72 * and 0 theta is measured from the +x axis to the +y axis.
73 *
74 * @param iwaypoints The waypoints to hit on the path.
75 * @param ipathId A unique identifier to save the path with.
76 * @param ilimits The limits to use for this path only.
77 */
78 void generatePath(std::initializer_list<PathfinderPoint> iwaypoints,
79 const std::string &ipathId,
80 const PathfinderLimits &ilimits);

82 /**
83 * Removes a path and frees the memory it used. This function returns true if the path was either

88 * @return True if the path no longer exists
